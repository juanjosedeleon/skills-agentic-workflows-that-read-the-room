## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent GitHub Blog and Changelog stories worth watching

- **Agent skills (GitHub Blog):** ["Build once, run on any agent: A practical guide to agent skills"](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/) shows how to write reusable skills for Copilot and other agents.
- **Agentic engineering (GitHub Blog):** ["Beyond code generation: A developer's guide to agentic engineering"](https://github.blog/ai-and-ml/github-copilot/beyond-code-generation-a-developers-guide-to-agentic-engineering/) is a practical overview of working with coding agents.
- **Pull request overview (GitHub Changelog):** [Improvements to the pull request overview](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview) are in public preview, which is useful for reviewing changes faster.
- **Pinned repositories (GitHub Changelog):** [Pin your favorite repositories to your dashboard](https://github.blog/changelog/2026-11-20-pin-your-favorite-repositories-to-your-dashboard) for quicker access.
- **GitHub Desktop (GitHub Changelog):** [Multiple accounts per host](https://github.blog/changelog/2026-11-19-github-desktop-now-supports-multiple-accounts-per-host) are now supported.
- **Awesome Copilot workflows:** The [workflows collection](https://github.com/github/awesome-copilot/tree/main/workflows) includes agentic workflow samples such as `daily-issues-report` and `weekly-comment-sync` to learn GitHub Actions automation from.
